# java-lotto-precourse

## 🚀 목표: 구입금액에 맞는 로또 번호를 생성하고 당첨번호 및 보너스번호를 입력하여 당첨 통계를 추출한다.

## ⚙️ 기능목록

> ### ** 로또 구입 **
>>1. 로또 구입금액을 입력 받는다.
   - 1-1. 금액은 1,000원 단위로 입력받는다(구매 금액 입력시 ,(콤마)가 있는경우는 제거후에 숫자만 받도록 할 수 있도록 한다.)
   - 1-2. 예외규칙 발생시 "IllegalArgumentException"을 던진다.
     - 1-2-1. 1,000원 단위로 나누어 떨어지지 않는 경우 예외 처리한다.
     - 1-2-2. 금액이 0원 이하로 입력하는 경우 예외 처리한다.
     - 1-2-3. 숫자가 아닌 다른 값이 입력되는 경우 예외 처리한다.

> ### ** 당첨 번호와 보너스 번호 **
>>2. 로또 당첨 번호를 입력 받는다.
   - 2-1. 입력번호는 6개로 번호는 쉼표(,) 기준으로 구분한다.
   - 2-2. 예외규칙 발생시 "IllegalArgumentException" 던진다.     
       - 2-2-1. 입력번호가 6개가 아닌경우 경우 예외 처리한다.
       - 2-2-2. 1~45번 범위가 아닌 경우 예외 처리한다.
>>3. 보너스 번호를 입력 받는다.
   - 3-1. 보너스 번호는 1개를 입력 받는다.
   - 3-2. 예외규칙 발생시 "IllegalArgumentException" 던진다.
     - 3-2-1. 보너스 번호가 당첨번호에 포함되는 경우 예외 처리한다.
     - 3-2-2. 1~45번 범위가 아닌 경우 예외 처리한다.

> ### ** 결과 출력 **
>>4. 금액에 맞는 로또를 생성하고 각 로또번호를 추출한다.
   - 4-1. 로또번호 출력시 로또번호는 오름차순으로 정렬한다.
   - 4-2. 예외규칙 발생시 "IllegalArgumentException" 던진다.
     - 4-2-1. 로또번호 생성실패하는 경우 예외 처리한다.
>>5. 당첨 통계에 대한 정보를 출력한다.
   - 5-1. 각 로또번호를 통해 당첨결과 내역을 출력한다.
   - 5-2. 당첨결과 내역에 따른 총 수익률을 출력한다.
     - 5-2-1. 수익률은 (수익금 ÷ 원금) × 100으로 계산한다.

## ✅참고사항
1. 예외 상황 시 에러 문구를 출력 한다. 단, 에러 문구는 "[ERROR]"로 시작 한다.
